しらす式 動く作戦図｜軍師の声Ver.
================================

このバージョンは通常版とは別のWebアプリです。
重要：現在の Shirasu-sakusen リポジトリに上書きしないでください。

【GitHub Pagesで別アプリとして公開する】
1. GitHubで新しいPublicリポジトリを作成（例：shirasu-gunshi-voice）。
2. このZIPをiPhoneの「ファイル」で解凍してください。
3. 解凍した index.html を新しいリポジトリの一番上にアップロード。
   （ZIPファイル自体をアップロードするのではありません）
4. Commit changes を押す。
5. Settings → Pages → Deploy from a branch → main → /(root) → Save。
6. 公開が完了すると以下のURLになります：
   https://tsurukabu.github.io/shirasu-gunshi-voice/
   ※実際のURLは作成したリポジトリ名によって変わります。

【使い方】
1. 砦／城を選び、スクショを読み込む。
2. A～D部隊・分岐ルート・総大将・井闌車などの作戦を描く。
3. 作戦名を入力し、再生速度を選ぶ。
4. 「軍師の声を録音して再生」を押してマイクを許可する。
5. 進軍アニメーションに合わせて解説する。最後まで進むか「録音終了」を押す。
6. 再生バーで録音を確認。必要なら「録音を削除」して撮り直す。
7. 必要に応じて「固定BGMも動画に入れる」を切り替える。
8. 「軍師の声入り動画を書き出す」を押す。

【注意】
録音はその端末・ブラウザ上でのみ利用でき、ページ再読み込みで消えます。
作戦JSONに録音データは入りません。音声が必要なら動画として保存してください。
録音時の再生速度が動画作成時にも適用されます。
マイク許可、音声の合成、動画書き出しは端末やブラウザの仕様に依存します。
iPhoneのSafariでは特に実機動作確認が必要です。
動画の形式はMP4またはWebMになる場合があります。
